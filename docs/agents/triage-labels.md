# Triage labels

| GitHub label | Use when |
| --- | --- |
| `needs-triage` | The maintainer needs to evaluate the issue. |
| `needs-info` | The issue needs more information before work can proceed. |
| `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | A person needs to do the work. |
| `wontfix` | The issue will not be worked on. |
